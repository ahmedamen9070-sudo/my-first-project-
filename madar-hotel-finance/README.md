# A&M
### Accounting Hotel for Audit &Control

**نيو بانوراما رمسيس — نسخة سطح المكتب**

برنامج محلي يفتح في نافذة تطبيق مستقلة، دون متصفح خارجي. الرئيسية بصورة فندق فخم تصورية واسم الفندق، وقسم الموردين يجمع ملفاته وبنوده وفواتيره. المشروع في مجلد مستقل داخل المستودع؛ ملفات البرنامج القديم لم تتغير.

## التنزيل والتشغيل

- افتح [حزمة سطح المكتب](AM-Accounting-Hotel-Desktop.zip) واضغط **Download raw file**.
- فك الضغط كاملًا، ثم افتح مجلد AM-Accounting-Hotel.
- على Windows مع Python 3.10 أو أحدث شغّل START_WINDOWS.bat. أول تشغيل يحتاج الإنترنت لتحميل مكونات النافذة؛ التشغيل اليومي محلي.
- يلزم Microsoft Edge WebView2 Runtime. تعليمات المتطلبات في [دليل التشغيل](app/README_AR.md).
- هذه حزمة مصدر وتشغيل وليست EXE مستقلًا عن Python. تم اختبار النافذة والطباعة على Linux/Qt. مشغل Windows لم يجرّب على جهاز Windows فعليًا.

## ما يعمل الآن

دورة الموردين: أنواع توريد متعددة لكل مورد، بنود مرتبطة بحساب المصروف والقسم، فواتير مصروفات وخدمات مستقلة عن الاستلام، وحفظ مسودة ثم اعتماد وترحيل بقيد متوازن. المرتجع الجزئي يرتبط بالفاتورة الأصلية ويستخدم سعرها وحساباتها تلقائيًا. السعر الافتراضي للصنف هو آخر شراء معتمد مع تنبيه فرق السعر.

السداد نقدي أو شيك أو تحويل أو إيداع بنكي أو إنستا باي أو بطاقة؛ تفاصيل ومستندات حسب الطريقة، سداد جزئي لفاتورة أو توزيع عام يدوي/بأقدم استحقاق، وفصل الدفعة المقدمة. تسوية الدفعات المقدمة وأرصدة المرتجعات على الفواتير، واسترداد نقدي أو بنكي، وعكس السداد وتتبع الشيك الموقوف والملغى والمرتد. كشف حساب وأعمار مديونيات ومطابقة مع القيود حتى تاريخ محدد، وطباعة بالتوقيعات وسجل تغييرات ونسخ احتياطي. الحزمة لا تتضمن بيانات المستخدم أو معاملات الاختبار.

العملة EGP والسنة يناير–ديسمبر. نسب الضرائب والأرصدة الافتتاحية لم تدخل بعد؛ رصيد مصدر السداد يعكس الحركات المسجلة مع تنبيه عند عدم كفايته، ولا يُفترض رصيد نقدي وهمي. بقية الموديولات والذكاء الاصطناعي ضمن الخطة. [دليل دورة الموردين](project-docs/SUPPLIER_ACCOUNTING_AR.md).

## تحديث المظهر المرجعي

الرئيسية بكحلي وذهبي وأيقونات مجسمة، ونوافذ إدخال فاتحة. [تفاصيل مرجع الشكل](project-docs/DESIGN_REFERENCE_AR.md). صور الخزينة المقدمة من المستخدم مرجع للشكل فقط؛ لا تعني تنفيذ وظائف خزينة أو ترحيل جديدة. حالة الاتصال تخص خدمة البيانات المحلية، وليست شهادة تشغيل كل الموديولات.

## شجرة الحسابات الفندقية

من «إعدادات الفندق» تتوفر شجرة تأسيسية من **250 حسابًا تأسيسيًا** و**43 ربطًا مقترحًا**؛ وتضيف دورة السداد حساب الشيكات الصادرة وربطه، فيصبح الإجمالي **251 حسابًا و44 ربطًا**. إضافة حساب بكود تلقائي، بحث وتعديل وحماية الارتباطات وتصدير CSV وطباعة. إعدادات مصر/EGP/يناير أكدها المستخدم. لا ترحيل أو أرصدة أو قيود من إنشاء الشجرة.
