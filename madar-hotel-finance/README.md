# A&M — Accounting Hotel for Audit &Control

 النظام المالي للفنادق

أول دورة تطوير فعلية: الموردون وبنود المصروفات والخدمات ومسودات الفواتير. هذا المشروع مستقل داخل المستودع؛ ملفات البرنامج القديم لم تتغير.

## التنزيل والتشغيل

- افتح [حزمة نسخة التجربة](AM-Accounting-Hotel.zip) واضغط Download raw file لتنزيل ZIP.
- فك الضغط، ثم افتح مجلد AM-Accounting-Hotel. على Windows مع Python 3.10+ شغّل START_WINDOWS.bat.
- على Linux أو macOS شغّل python3 run.py. المشغل يفتح المتصفح محليًا.
- لتشغيل المصدر مباشرة، افتح مجلد app وشغّل python3 run.py.

لا توجد حزم خارجية مطلوبة. يلزم Python 3.10 أو أحدث ومتصفح حديث. تم الاختبار على Linux وChromium؛ مشغل Windows لم يختبر على Windows فعليًا.

## المتاح وحدوده

موردون وبنود وأقسام بمراكز تكلفة تلقائية، فواتير مصروف أو خدمة مستقلة عن الاستلام، أكواد تلقائية، بحث وتعديل وإلغاء مسودة وطباعة بتوقيعات وسجل تغييرات ونسخ احتياطي محلي. البيانات تحفظ في SQLite محليًا. الحزمة لا تحتوي معاملات اختبار أو قواعد بيانات المستخدم.

الفواتير مسودات فقط ولا تنشئ قيودًا أو ترحيلًا أو حركة مخزون. العملة والضرائب لم تضبطا بعد، وباقي الموديولات والذكاء الاصطناعي ضمن الخطة ولم تنفذ. التطبيق للتجربة المحلية ولم يجهز للنشر العام.

## الاختبارات

من مجلد app: python3 -m unittest discover -s tests -v

اختبار المتصفح tests/browser.cjs يحتاج أدوات تطوير Playwright وChromium وخادمًا بقاعدة مؤقتة على المنفذ 8091؛ لا تشغله على قاعدة مستخدم فعلية.
